# Screenshots

Drop these four PNGs in this folder (same filenames — the main README already links to them):

| File | Page | What to capture |
|---|---|---|
| `library.png` | Library | The artist grid with cover art |
| `artist.png` | An artist's page | Wanted / downloaded releases list |
| `queue.png` | Queue | A few active/queued downloads, ideally showing a collaboration credit |
| `settings.png` | Settings → Sources | The tabbed settings layout |

Keep them at a reasonable width (~1400px) and in dark mode to match the app's default theme.
